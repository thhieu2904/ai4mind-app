# Public Assets

## Logo và Favicon

### Files

- **logo.png**: Logo chính của AI4Mind (hiển thị trong header)
- **favicon.png**: Favicon cho website (hiển thị trên tab trình duyệt)

### Thông tin

- Logo được thiết kế với hình ảnh đám mây và bộ não, thể hiện ý tưởng về sức khỏe tâm thần và AI
- Màu sắc chính: Gradient từ tím (#A78BFA) đến xanh dương (#93C5FD)
- Logo tự động responsive trên các thiết bị khác nhau

### Sử dụng

Logo được sử dụng trong:

1. Header component - Có thể click để quay về Dashboard
2. Favicon - Hiển thị trên tab trình duyệt
3. Apple Touch Icon - Khi lưu trang web vào màn hình chính iOS

### Vị trí trong code

- Header: `src/components/layout/Header/Header.tsx`
- HTML: `index.html`
- CSS: `src/components/layout/Header/Header.css`
